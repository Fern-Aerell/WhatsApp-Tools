# WhatsApp Tools  

**WhatsApp Tools** is a tool designed to simplify WhatsApp usage in various cases, such as broadcasting, extracting numbers from groups, and other functions. With WhatsApp Tools, you can execute commands directly from a private chat using the `/` prefix, allowing you to automate and speed up various tasks on WhatsApp.  

## Key Features  
- **Number Check**: Quickly check whether a number is registered on WhatsApp without manually verifying each one.  
- **Scripts**: Create your own custom scripts.

- **Execute Commands with `/` Prefix**: Run special commands by simply typing them in your private chat, without needing additional apps or tools.  
- **Easy Integration**: WhatsApp Tools integrates directly with your WhatsApp account without requiring complicated installation processes.  

## How to Use  

1. **Installation**: Ensure you have installed and set up **WhatsApp Tools** on your device.  
2. **Chat with Yourself**: Open your private chat on WhatsApp.  
3. **Enter a Command**: Type a command using the `/` prefix, such as `/service`, `/halodunia`, or any other supported command.  
4. **Execute the Command**: WhatsApp Tools will automatically run the command you entered.  

## Commands  

- `/args_test [arguments]` - Test command arguments.  
- `/halodunia` - Sends a "halodunia" message to yourself.  
- `/service stop` - Stops the service.  
- `/number [country code] check [number]` - Checks if a number is registered on WhatsApp.  
- `/script [script name]` - Runs a custom script you created.
